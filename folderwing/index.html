WINDOWS AT HOME. LINUX WITHIN REACH.

Both sides of
your workspace.

Folderwing runs as a native Windows app. If you use WSL, your installed distributions sit alongside your drives, with native Linux helpers for file operations and analysis.

WSL is optional. So are Git and Everything search; install them separately to enable their integrations. The Direct agent client is a separate optional installation and is not bundled.
